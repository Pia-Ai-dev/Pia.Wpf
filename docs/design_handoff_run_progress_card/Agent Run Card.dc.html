Reading of the brief
Two problems to solve. (1) Too quiet at a glance — the state chip is the only signal, and it competes with four greys. Every option below gives state a structural home (a band, a rail, a strip) rather than just a colour on 12px text. (2) Tool activity reads as a log dump — 20 identical rows in time order. Every option re-frames it as an audit: grouped by step or summarised by decision, with the exceptions (Awaiting / Denied / Blocked) pulled out of the stream.
Constraints honoured. Segoe UI only, no blur/glass, no gradients WPF can't do cheaply; Pia tokens for colour (accent #0078D4, success #16A34A, ink ramp, warm paper). The ledger is demoted everywhere — shown on hover or behind the header. Long plans: I've assumed a windowed list — the running step ±2 rows, with "+7 earlier" / "+4 later" fold rows — shown in 1c. Personas: kept as a small ringed avatar but moved onto the rail so it never pushes the title.
